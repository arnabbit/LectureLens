3Sum - Array Manipulation

account_circle
Problem Statement

Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and the sum of the elements equals zero.

Medium Arrays Two Pointers

Approaches

Optimized: Sorting & Two Pointers

star
O(n²) Time O(1) Space

Sort the input array first. Iterate through the array, and for each element, use two pointers (left and right) to find pairs that sum to the negative value of the current element.

Key optimization: Skip duplicate elements during iteration and pointer movement to avoid duplicate triplets in the result set.

Recursive Hashing

O(n²) Time O(n) Space

lightbulb Critical Insights

  • Sorting is the prerequisite for the Two Pointer technique here; it allows us to intelligently move pointers based on the sum's comparison to zero.

  • Handling duplicates is the most error-prone part. Always use while loops to skip identical values.
